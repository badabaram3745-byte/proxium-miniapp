# Proxium Mini App, Railway-ready

نسخه نهایی با ظاهر کهکشانی سه‌بعدی و مسیر دریایی مستقل، بدون حذف قابلیت‌های قبلی.

## تغییرات این نسخه
- طراحی کهکشانی جدید با command-deck، grid نورانی، کارت‌های angular، planet 3D و نورپردازی عمیق.
- سرویس‌ها، پروفایل، راهنما و خرید هرکدام چیدمان اختصاصی خودشان را دارند.
- تم دریا layout مستقل دارد: کارت‌های افقی، پنجره‌ای، sea-glass و موج‌های نرم.
- صفحه واقعی «شارژ کیف پول» با مبالغ پیشنهادی و ادامه در ربات؛ پرداخت نهایی طبق flow امن خود ربات انجام می‌شود.
- دکمه «بازگشت به ربات» و شارژ از پروفایل به bot username واقعی وصل هستند.
- حذف سرویس از داخل مینی‌اپ با تأیید، ابتدا از پنل و بعد از دیتابیس ربات.
- تاریخچه تراکنش‌ها، چندپنل، تست، تخفیف، مصرف، تمدید، QR و پروفایل حفظ شده‌اند.

## Railway
Root Directory خالی یا `/` باشد. یک بار Clear build cache بزن. متغیرهای `BOT_TOKEN` و `ADMIN_IDS` لازم‌اند. برای SQLite ماندگار، Volume روی `/data` و `DB_PATH=/data/bot.db` تنظیم کن.
